# 📅 Daily Execution Checklist

> **Har din ye follow kar. No thinking. No planning. Just execute.**
> **Print karke desk pe rakh. Daily check off kar.**

---

## ⏰ Morning Block (1 hour — 9:00 to 10:00 AM)

- [ ] **09:00** — Check LinkedIn notifications + messages (5 min)
- [ ] **09:05** — Apply to 3 LinkedIn jobs — "AI Engineer" / "Python Developer" / "Backend Engineer" (15 min)
- [ ] **09:20** — Apply to 2 Wellfound/AngelList jobs (10 min)
- [ ] **09:30** — Send 3 customized Upwork proposals (15 min)
- [ ] **09:45** — Send 2 LinkedIn connections to founders/CTOs/recruiters (5 min)
- [ ] **09:50** — Check Fiverr for buyer requests (5 min)
- [ ] **09:55** — Update application tracker (Google Sheet) (5 min)

**Daily Target: 5 applications + 3 proposals + 2 connections = minimum**

---

## 🔨 Build Block (2-4 hours — flexible)

- [ ] Code on current project (RAG agent, flagship project, or client work)
- [ ] Push at least 1 real commit to GitHub
- [ ] Write meaningful commit messages: `feat:`, `fix:`, `docs:`, `refactor:`

---

## 📱 Content Block (30 min — pick one)

### Monday: Post on LinkedIn (technical or project update)
### Tuesday: Engage — comment on 5-10 AI/startup posts (thoughtful, not "Great post!")
### Wednesday: Demo post — screenshot or screen recording of a project
### Thursday: Engage + send 10 connection requests
### Friday: Career insight or "what I learned" post
### Saturday: Short technical tip or hot take
### Sunday: Review weekly metrics

---

## 🌙 Evening Check (15 min — before bed)

- [ ] Check all platforms for responses (LinkedIn, Fiverr, Upwork, email)
- [ ] Reply to any messages within 1 hour of seeing them
- [ ] Plan tomorrow's Upwork proposals (pick 3 jobs to apply to)
