## 📋 What is a Data Annotator?
A Data Annotator **labels/tags data** so that AI models can learn from it:

### Types of Annotation You'll Do:
- **Document Classification:** Is this a hospital bill? Prescription? Lab report?
- **Named Entity Recognition (NER):** Mark patient name, date, amount, hospital
- **Bounding Box:** Draw rectangles around text fields in scanned documents
- **Key-Value Pairs:** Link labels to values (e.g., "Total Amount: Rs 45,000")
- **OCR Verification:** Check if the AI-read text matches the actual document

### Daily Work:
1. Open a medical document in annotation tool (like LabelStudio, CVAT, or custom tool)
2. Follow annotation guidelines strictly
3. Label specific elements (names, dates, amounts, diagnosis codes)
4. Ensure consistency with quality standards
5. Meet daily targets (typically 100-200 annotations/day)
6. Flag ambiguous or unclear documents for review

### TECHNICAL QUESTIONS

**Q4: "What is data annotation?"**
> "Data annotation is the process of labeling raw data — like images, text, or documents — so machine learning models can learn patterns. For insurance document processing, this means labeling where the patient name is, where the claim amount is, what type of document it is. This labeled data becomes the training set for AI to automatically process new claims."

**Q5: "What types of annotation do you know?"**
> - **Bounding Box:** Drawing rectangles around text or objects
> - **Named Entity Recognition (NER):** Labeling entities like names, dates, amounts
> - **Semantic Segmentation:** Pixel-level labeling
> - **Classification:** Categorizing entire documents (invoice vs prescription vs lab report)
> - **Key-Value Pair:** Linking labels to values (Patient Name: Azad Ansari)
> - **OCR Verification:** Checking AI-extracted text against original document

**Q6: "What is OCR?"**
> "OCR stands for Optical Character Recognition. It converts images of text into machine-readable text. For insurance, OCR reads scanned hospital bills and prescriptions. But OCR isn't perfect — it makes errors especially with handwritten text or poor scans. That's where annotators help — we verify and correct OCR output."

**Q7: "What is IDP (Intelligent Document Processing)?"**
> "IDP uses AI to automatically classify, extract, and validate information from documents. It combines OCR, NLP, and machine learning. i3systems uses IDP to process insurance claims — auto-reading hospital bills, extracting amounts, and checking against policy rules."
