# 📓 Developer Log

Daily notes on what I'm building, learning, and shipping.

Each entry is a real record of my development journey — what I worked on, problems I solved, and what I learned.

---

## How to Use

1. Create a new file: `devlog/YYYY-MM-DD.md`
2. Write 3-5 lines about what you did
3. Commit and push

## Template

```markdown
# YYYY-MM-DD

## What I Built / Worked On
- [describe what you coded today]

## Problems Solved
- [any bugs fixed, errors debugged]

## What I Learned
- [new concept, tool, or technique]
```
