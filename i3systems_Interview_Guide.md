## 💼 Data Annotation Specialist — Job Kya Hai?

### Daily Work Breakdown:

| Task | Description | % of Day |
|------|-------------|----------|
| **Document Reading** | Medical reports, bills, claim forms padhna aur samajhna | 30% |
| **Data Labeling** | Proprietary software me documents ke specific fields ko tag/label karna | 40% |
| **Quality Check** | Apne aur team members ke annotations verify karna | 15% |
| **Guideline Following** | Annotation guidelines follow karna, training attend karna | 10% |
| **Reporting** | Daily/weekly progress report submit karna | 5% |

### Specific Kya Karna Padega:

1. **Medical Documents Padhna** — Hospital bills, pathology reports, doctor prescriptions
2. **Fields Extract Karna** — Patient name, diagnosis, amount, procedure codes, dates
3. **Labels Lagana** — Har field ko correct category me tag karna (e.g., "diagnosis", "treatment_cost", "hospital_name")
4. **Consistency Maintain Karna** — Same type ke documents me same labeling pattern follow karna
5. **Edge Cases Handle Karna** — Blurry scans, handwritten notes, non-standard formats

> [!NOTE]
> **Medical terminology seekhni padegi** — Company training degi, but basic medical terms (diagnosis, prognosis, pathology, radiology, etc.) pehle se seekh lo toh interview me plus point hoga.

I've built AI projects including data validation engines. I'm looking to apply my data processing precision to AI training data at i3systems." |

| **"Rotational shifts ok?"** | "Yes, absolutely. I mentioned this in my resume — I'm fully comfortable with rotating shifts." |

### Round 2: Technical/Practical Questions

| Question | How to Answer |
|----------|---------------|
| **"What is data annotation?"** | "Data annotation is the process of labeling raw data — images, text, documents — with meaningful tags so that machine learning models can learn from it. For example, in insurance, we label fields like patient name, diagnosis, claim amount in medical documents." |
| **"What is OCR?"** | "Optical Character Recognition — it converts scanned documents or images of text into machine-readable text. In insurance, OCR is used to digitize paper medical bills and claim forms." |
| **"What is IDP?"** | "Intelligent Document Processing — it combines OCR, NLP, and ML to automatically extract, classify, and validate data from unstructured documents like invoices, medical reports, and claim forms." |
| **"How do you ensure quality?"** | "I follow a three-step approach: First, understand the annotation guidelines thoroughly. Second, cross-verify my labels against the guideline examples. Third, self-audit my work before submission by randomly sampling 10-20% of completed annotations." |
| **"Experience with classification?"** | "At DMart, I classified 50+ product categories daily with 100% database integrity. In my AI projects, I built classification systems — ClawBot classifies user intents into 32+ categories." |
| **"Handle ambiguous data?"** | "I flag it for review rather than guessing. Accuracy is more important than speed in annotation. I document the ambiguity and follow the escalation process defined in the guidelines." |

### Round 3: Practical Test (Possible)

> [!TIP]
> They might give you a **sample document** (medical bill/report) and ask you to annotate it. Practice this:
> - Read a sample hospital bill
> - Identify: Patient Name, Hospital, Date, Diagnosis, Treatment, Amount, Doctor Name
> - Label each field clearly
> - Note any unclear/missing information

| **Underwriting** | Risk assessment for insurance |

| **ICD Codes** | Disease classification codes |

### Must-Know AI/Annotation Terms:
| Term | Meaning |
|------|---------|
| **NER** | Named Entity Recognition — text me entities (name, date, amount) identify karna |
| **Bounding Box** | Image me object ke around rectangle draw karna |
| **Semantic Segmentation** | Image ke har pixel ko label karna |
| **Inter-Annotator Agreement** | Multiple annotators ke labels ka consistency measure |
| **Gold Standard** | Perfect, verified annotation jo reference ke liye use hoti hai |
| **Annotation Guidelines** | Rules document jo batata hai kaise label karna hai |
| **Edge Case** | Unusual/difficult examples jo standard rules me fit nahi hote |
| **Ground Truth** | Correct, verified data jo model training me use hoti hai |
